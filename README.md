# InBest · 주가 데이터와 뉴스 분석 실험

상한가를 기록한 종목이 이후 10거래일 안에 추가로 20% 상승하는지를 연구한 팀 프로젝트입니다. 수치·이미지 기반 주가 분석과 뉴스·LLM 실험을 진행하고, 종목 정보와 분석 결과를 살펴보는 Streamlit 화면으로 연결했습니다.

**문영식의 담당 영역은 뉴스 수집·분석, LLM 활용 실험, 웹 서비스 구현입니다.** 주가 예측의 검증된 수익률을 제시하는 서비스가 아니라, 데이터 분석과 사용자 화면을 연결한 실험 기록입니다.

## 역할과 코드

| 참여자 | 담당 영역 | 위치 |
| --- | --- | --- |
| 문영식 | 뉴스 수집·분석, LLM 실험, Streamlit 웹 화면 | [mys](mys) |
| 정호석·최희범 | 증권 데이터 수집·가공, 다수 피처 및 주가 이미지 기반 딥러닝 실험 | 저장소 내 팀원별 작업물 |

## 직접 구현·실험한 흐름

1. 종목 관련 뉴스를 수집하고 분석에 사용할 데이터를 정리했습니다.
2. 감성 분석, 텍스트 분류와 임베딩을 실험하며 상한가 관련 신호를 찾을 수 있는지 살폈습니다.
3. Streamlit에서 종목을 선택하고 주가·거래량·이동평균·볼린저 밴드 등을 확인하는 화면을 구성했습니다.
4. Ollama의 Gemma 2를 호출하는 대화 UI와 세션 기록을 연결했습니다.

뉴스 감성만으로 특정 주가 움직임을 설명하기에는 한계가 있었고, KrFinBERT 조정에서도 기대한 개선을 얻지 못했습니다. 시도와 한계는 [개인 실험 기록](mys/README.md)에 남겼습니다. 화면의 모델 출력은 검증된 투자 판단이나 성과를 의미하지 않습니다.

## 코드 읽는 순서

- [Streamlit 진입점](mys/.streamlit/main.py): 화면 구성 시작
- [종목 검색](mys/.streamlit/sidebar_sctock_search.py): 종목 목록과 데이터 연결
- [개인 작업 폴더](mys): 뉴스 수집·모델 실험 노트북과 UI 코드

## 실행 전 준비

실험 당시의 로컬 CSV 절대 경로와 한국어 locale 설정이 코드에 남아 있습니다. 데이터 경로를 현재 환경에 맞추고, 노트북·UI에서 사용하는 라이브러리와 Ollama의 `gemma2` 모델을 준비해야 합니다. `requests.txt`는 당시 환경 기록이므로 최소 의존성 목록으로 보기는 어렵습니다.

준비 후 저장소 루트에서 실행합니다.

```sh
streamlit run mys/.streamlit/main.py
```

데이터 준비와 외부 모델 구동이 필요한 연구용 프로젝트이며, 복제 직후 실행되는 배포 패키지는 아닙니다.
